# 批量分拣：产品交互与技术方案

日期：2026-09-15

## 目标与边界

批量分拣用于对数据集详情页中明确选中的最多 200 张图片统一修正分拣元数据。它补充单张快速分拣，不替代连续看图判断，也不根据当前筛选隐式扩展选择范围。

本功能只修改 SQLite 中的分拣元数据，不移动、重命名、覆盖或删除原始图片，不修改普通标签、split、审核状态和几何标注。

## 产品交互

入口沿用样本详情页现有多选工具条。选择至少一个样本后显示“批量分拣”；超过 200 个时按钮禁用并解释上限。

完整流程：

1. 用户打开“批量分拣”，弹窗明确显示选择数量、200 张上限和整批提交规则。
2. 每个字段单独选择操作语义。默认全部为“保留”，因此打开弹窗不会产生隐式覆盖。
3. 用户点击“预览变更”。服务端基于当前分拣层级、样本版本、文件 hash 和缺陷类型计算逐项前后值，不写数据库。
4. 预览显示将修改、无需变化和被阻断的数量，并逐张显示原值、新值和阻断原因。存在任一阻断或没有实际变化时不能提交。
5. 用户点击“确认应用”。如果预览后任一样本的分拣版本、文件内容或数据集分拣层级变化，服务端返回冲突，整批不写入并要求重新预览。
6. 成功后刷新数据集概览和样本网格，保留当前选择，便于用户核对或执行下一项批量操作。

任一操作条件变化都会使已有预览失效，必须重新预览。

### 字段语义

| 字段 | 可选操作 | 语义 |
| --- | --- | --- |
| 判定 | 保留、设置待确认/OK/NG、清空 | 清空判定等价于恢复未分拣，并明确清空全部分拣详情 |
| OK 等级 | 保留、设置、清空 | 只有当前层级细分 OK 时可以设置完全/勉强 |
| 缺陷程度 | 保留、设置、清空 | 只有当前层级启用程度时可以设置 |
| 缺陷类型 | 保留、追加、替换、清空 | 追加与原类型取并集；替换丢弃原类型；均不允许空选择 |
| 主要缺陷 | 保留、设置、清空 | 设置后的主要缺陷必须存在于该样本最终类型集合中 |
| 备注 | 保留、设置统一备注、清空 | 设置空备注无效，清空必须显式选择 |

字段组合不合法时不自动猜测。例如，将已有完全 OK 图片追加缺陷类型会在预览中阻断；用户需要同时调整 OK 等级/判定或清空冲突字段。

## API 契约

### 只读预览

`POST /api/datasets/{dataset_id}/triage/batch-preview`

请求包含 1–200 个去重后的明确 `sample_ids` 和字段操作。响应包含：

- 当前 dataset revision 和分拣层级版本；
- `changed`、`unchanged`、`blocked` 与 `can_apply`；
- 每张图片的路径、原值、新值、版本、文件 hash 和错误；
- 规范化操作与期望样本状态生成的 `preview_hash`。

### 事务提交

`POST /api/datasets/{dataset_id}/triage/batch`

提交复用预览返回的 `policy_version`、`preview_hash`、`expected_samples` 以及完全相同的操作。服务端重新计算预览 hash、重新读取全部样本并重新执行语义校验。

提交使用一个 SQLite 事务：

1. 在写入前核对所有样本均属于当前数据集且为图片。
2. 核对全部 `triage_version`、`file_hash` 和分拣层级版本。
3. 为全部样本计算最终状态并完成校验。
4. 只更新有变化的样本；任一条件更新失败立即回滚。
5. 成功批次只递增一次 dataset revision；无变化批次不递增。

批量接口返回 Pydantic 响应对象，不返回 ORM 对象。无数据库结构变化，因此不新增迁移。

## 代码结构

- `backend/app/schemas/triage.py`：操作、预览、期望状态和提交响应模型。
- `backend/app/services/triage_service.py`：字段变换、逐项校验、预览 hash 与单事务提交。
- `backend/app/api/triage.py`：薄路由与既有错误状态映射。
- `frontend/src/components/BatchTriageModal.tsx`：字段操作、预览、逐项差异和二次确认。
- `frontend/src/components/BatchActionBar.tsx`：明确选择后的入口。
- `backend/tests/test_triage_api.py`：接口、字段语义、冲突回滚、阻断和上限测试。

## 验证重点

- 保留、设置、清空、类型追加和替换的最终状态正确。
- 两张以上图片一次提交只递增一次 dataset revision。
- 预览后竞争修改任一样本时，未冲突样本也不发生部分写入。
- 非法字段组合在预览逐项显示并阻止提交。
- 篡改预览 hash、超过 200 张、跨数据集/非图片样本均被拒绝。
- 提交前后原始图片内容和目录不变。
