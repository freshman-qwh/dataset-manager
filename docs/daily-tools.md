# 日常浏览与对照

项目工作台、数据集名片和正常与缺陷对照沿用现有项目、数据集、对象类别与采集批次，不增加新的管理层。浏览和对照不会修改原图，也不会自动改变样本判定。

## 从首页继续工作

首页就是项目工作台，无需另建工作空间。

- 用“全部项目”筛选器查看某个项目的数据集，或查看“未归属项目”。
- “最近打开”按实际访问记录排列；“继续浏览”回到该数据集上次的本地浏览位置，包括来源、文件夹、类别、批次、搜索和页码等已保留条件。
- 点击数据集卡片右上角的图钉置顶常用数据集，再次点击取消置顶。置顶只影响首页排列。
- 最近访问、浏览位置和置顶偏好保存在当前浏览器的 `localStorage`，不写入数据库，也不会随数据库备份或在其他浏览器同步。清理浏览器数据后需要重新积累。

没有访问记录时，可直接浏览一个数据集；工作台会逐步形成常用入口。项目、类别与批次的整理仍使用原有的“管理项目”和“类别与批次”，详见[项目、类别与批次](project-category-batch.md)。

## 生成数据集名片

在“本地浏览”打开数据集，点击“数据集名片”；也可在数据准备页展开“管理与导出”后打开。

名片汇总整个数据集的已登记信息，包括图片、对象类别、采集批次、正常与异常判定、划分和代表图片，不受当前目录或分页限制。点击“下载 PNG”保存图片；分拣或登记信息变化后，可点击“重新生成”。名片不展示原始文件路径。

“关联 Mask”表示记录已关联 Mask，不保证每个 Mask 文件都能读取。代表图只选取少量图片；读取失败时保留占位并提示数量。名片用于快速介绍数据，不代表原图完整性检查、像素级标注质量或模型效果。

## 查看正常与缺陷对照

从本地浏览进入“正常与缺陷对照”，先确认对象类别，再按需选择采集批次。默认自动选取一个有图片的类别；两栏始终限定在同一类别下，不会混入其他类别的正常参考。选择“全部批次”可查看该类别的所有批次，来源文件夹不限制对照范围。

- 左侧“正常参考”、右侧“缺陷样本”各自切换缩略图、上一张/下一张和分页；聚焦某侧大图后，可用左右方向键切换该侧本页图片。
- 顶部缩放同时作用于两侧；放大后拖动或滚动大图，两侧按相对位置同步。“还原”恢复初始缩放和位置，不做图像配准。
- 缺陷样本有关联 Mask 时，可勾选“显示 Mask”叠加查看；该操作不修改原图或 Mask。
- 点击“返回浏览位置”回到进入对照前的本地浏览范围。某栏为空时，可调整类别或批次，或返回浏览完成分拣。

只有当前有效的正常、异常判定且登记文件状态可用的图片进入两栏。待定（pending）、过期判定、缺少可用真值的未知样本以及已登记为不可用的图片被排除，页面提示当前类别与批次范围的排除数量。文件在登记后变得不可访问时，大图会提示重新读取。

当前有效的人工 OK / NG 优先于官方真值；尚未人工分拣的样本才使用已登记的官方正常/异常真值。人工判为待定或判定已过期时，不会退回旧的官方真值充当确认结果。“边界正常”仍可作为对照参考，但不等同于纯正常训练候选。对照是查看已有判定的工具，不是模型效果评估，也不会自动作出或写入判定。

这三项工具使用现有元数据与浏览器偏好，不新增数据库表或迁移。原目录有新增或移动文件时，仍应通过原有扫描流程更新登记，参见[本地浏览](local-browsing.md)。
