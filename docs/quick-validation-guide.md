# 工业数据快速验证使用指南

本指南对应当前源码。2026-10-30 的便携 ZIP 仍保留当日交付能力，未包含后续新增的快速验证页面。

工具定位：把本地工业图片整理成可信输入，用正常图片建立一个可复查的异常检测基线，再找到需要补采或人工核对的图片。合成示例用于熟悉流程，不能证明真实产品或产线效果。

## 从数据准备到第一次验证

1. 选择工业异常检测用途，扫描本机图片并完成快速分拣。完全 OK 是正常拟合候选；NG 用于评估；待定、过期判定和不可用图片需先处理。
2. 填写工件和采集批次。同一工件的连拍、多角度图片属于同组。文件名规则可先预览再整批确认，并保存供后续数据复用。
3. 点击“快速验证”。第一次选择已有 Anomalib 2.7.0 的 Python，或用本机 Python 创建独立 CPU 环境。本机实际验证环境为 Python 3.13；首次安装需下载较多组件，首次建模缓存约 45 MB 官方 ResNet18 权重。安装及运行可查看日志、取消或重试；整理和导出不需要算法环境。
4. 选择目的与明确范围：有正常/异常独立采集组时使用独立评估；只有正常图片时使用正常一致性探索。后者至少需要两个独立正常组，并保证至少两张正常拟合图，只评价正常误报与分数分布。
5. 默认先用 PaDiM，按需用 PatchCore 对照。高级设置可改输入尺寸。单次 CPU 验证最多 256 张拟合图、2000 张总图；整组隔离优先于数量比例。
6. 相机位置固定时，可启用矩形检测区域，在参考图上拖框或填写比例。区域按 EXIF 校正后的原图比例应用，检查时逐图确认至少 4 × 4 像素。保存为项目默认只影响新实验，不修改原图和已有模型。
7. 按“检查数据与拟合方案”，核对实际纳入/排除数量及原因，再确认运行。预览不写回原 split。验证记录保留输入、人工真值、配方和模型。

运行时会复制本次输入并在复制中核对内容，算法使用这些冻结副本。复制前图片变化会要求重新扫描；复制完成后原目录独立变化不使该次计算作废。当前项目判定或分组版本变化仍需重新检查，历史结果不随之后的改判重写。

独立评估要求纯正常 train，以及各有正常/异常的 val 和 test。组或图片不足时补采数据，不复制图片凑数。原来的“划分与导出”仍可生成独立读取的训练包。

预检后的“交付目标验收清单”复用本次冻结输入，按所选目的区分必须处理、方案排除和提示；可展开问题样例，或在新标签页“分拣这张”。正常探索无需补 NG，清单不会把探索结果说成异常检出率或独立测试结论。类别/批次覆盖、完整隔离组候选口径和范围外关联的说明见[交付目标清单](industrial-trial-guide.md#按交付目标核对验收清单)。

清单通过后仍需点击原有“确认输入，运行基线”，并满足组件就绪条件；检查和看图不会启动算法。人工改判、分组、ROI、目的或范围变化后重新检查，历史实验的输入和结果保持原值。后续图片先在同一数据集通过[新批次接收方案](project-category-batch.md#新批次接收方案)完成扫描与元数据补空，再选择建立新实验或[沿用已有模型预测](#用同一模型验证第二批)。

## 看懂结果并复核

- 验证集分布和阈值只使用验证图片。异常分数不是概率；默认阈值来自验证 F1，只有正常时使用正常分数经验分位。
- 点正常、异常、误报、漏检卡片查看对应图片。可切换原图/预测热图、调整透明度、查看正常拟合参考，用方向键切图。ROI 外不参与评分，热图映回原图对应位置；同一模型共用原验证集强度标尺。
- 明确冻结阈值后才开启测试分数、测试图及测试报告。继续调滑块仅预览验证集，已经冻结的测试结果不变。已在其他实验开启过的相同测试内容会标记为开发参考；应用内首次开启也不能代替真实采集独立性的确认。
- 将一张或本页图片加入人工复核，进入只包含这些候选的分拣队列。确认保留或更改人工判断后保存；待定仍留在候选。模型预测不会自动改判。
- 返回本次实验时保留筛选、图片与阈值。旧实验仍使用当时的人工真值，当前改判会显示变化提示。下载结果报告可保留配方、逐图分数和已开启的冻结评估。没有像素真值时不提供像素指标。

## 用同一模型验证第二批

1. 将新批次扫描到工业项目，填写真实采集组和批次；可先分拣，也可保留未知真值。
2. 在原实验冻结阈值后点“用此模型验证新批次”，选择目标项目并检查纳入/排除。与原输入及该模型历史批次重复的内容或采集组整组排除；相同内容存在矛盾真值也会排除。
3. 确认后只运行预测，固定沿用原模型、图像处理、ROI、热图标尺和阈值，不重新拟合。新批次未知真值只显示预测，不充当正确结果，也不进入误报/漏检分母。
4. 需要更改 ROI、算法或阈值时新建实验，保留对照。原模型被后续批次引用时不可删除；先删除后续批次记录。删除结果不清除测试内容已被查看的历史，也不删除原图。

## 建模前的数据质量检查

在快速验证页展开“数据质量检查”。它沿用上方数据范围和 ROI，每次检查 1–300 张图片。超过上限时回数据页筛选/选择后带入。

亮度为灰度均值；清晰度为统一缩放后的边缘方差，低纹理不等于失焦；近重复为 64 位差异哈希候选，不证明同工件。参数需要结合产品、相机和背景判断。相似对最多显示 200 对，可点击并排核对；候选可在新标签页进入项目分拣。体检不自动删图、改标签或合并采集组，改变范围/ROI/参数后需重新检查。

此检查只解码图片计算指标，利用文件大小、修改时间等信息提示过期或检查中变化，不反复读图做全文校验。精确重复继续复用扫描时记录的内容指纹；发现文件变化时先重新扫描。

## 备份与当前验收边界

首页数据库维护的工作区 ZIP 包含 SQLite、快照、冻结计划、复核元数据、验证模型、热图及结果预览，并校验文件、模型关联和表计数。上限为 20000 文件 / 2 GiB；其他任务结束后备份。轻量 `.db` 不含模型等外部文件。

原图、算法环境、权重缓存、缩略图和历史下载包需另行保留。恢复到新位置后可查看已保存的结果，继续运行前重新选择或创建算法环境；原图改位置通过已有目录修复流程处理。
