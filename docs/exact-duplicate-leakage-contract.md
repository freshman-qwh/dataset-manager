# 精确重复与跨划分泄漏契约

## 目标与边界

E2B 复用扫描阶段记录的 SHA-256，为研究数据整理提供可解释的精确重复与跨训练划分泄漏视图。它不计算 embedding，不判断视觉近似，不接外部 AI，也不自动移动、改名、删除或覆盖任何原始文件。

精确重复组是同一数据集中 `file_hash` 非空且样本数大于 1 的集合。跨划分泄漏组必须同时覆盖 `train`、`val`、`test` 中至少两个不同划分；自定义 split 和未分配样本不参与“是否泄漏”的判定，但如果所在 hash 已构成泄漏，仍返回这些样本作为完整上下文。

## API

`GET /api/datasets/{dataset_id}/duplicates` 接受：

- `leakage_only`：默认 false；为 true 时明细只返回跨训练划分泄漏组。
- `page`：从 1 开始，超出末页时夹取到末页。
- `page_size`：默认 20，范围 1–100。

响应中的 `group_count`、`duplicate_sample_count`、`cross_split_group_count` 和 `cross_split_sample_count` 始终代表全数据集；`filtered_group_count` 代表当前 `leakage_only` 范围。`groups` 仅包含当前页，泄漏组优先，其后按样本数倒序和 hash 稳定排序。

每组返回 SHA-256、样本数、泄漏标记、涉及的训练划分、split 计数，以及样本的相对路径、文件状态、split、审核状态和标注进度。单组内联明细最多 20 个，并以 `samples_truncated` 明确是否截断；完整组通过 SHA-256 进入已有分页样本列表查看。接口不返回文件字节，也不执行元数据或原始文件写入。

## 查询与界面约束

报告使用数据库分组、条件聚合、分页和组内窗口限制，只读取当前页每组前 20 个样本。一次有结果的报告保持最多 3 次 SELECT：摘要与数据集校验、分页组、当前页有界样本；查询次数与返回规模均不随数据集规模无界增长。

详情页重复弹窗同时展示全局精确重复和跨划分泄漏摘要，支持仅泄漏筛选与分页。单组定位复用样本列表已有的完整 hash 搜索和重复虚拟状态筛选，使筛选条件保持可见；该动作只改变前端查询，不修改 split 或其他 SQLite 元数据。

## 后续门槛

E2C 只先评估近重复/唯一性契约：输入 embedding 的来源与指纹、模型/维度、归一化、距离度量、阈值、候选分页、唯一性分数、应用 storage 缓存和资源上限。未通过可复现性与容量门槛前，不引入模型下载、GPU、向量数据库或外部 AI 服务。
