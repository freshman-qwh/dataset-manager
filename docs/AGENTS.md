# 文档维护规则

继承根 [AGENTS.md](../AGENTS.md)。本文件仅补充 `docs/` 范围。

- 查找资料先看 [README.md](README.md)。新文档只有提供独立操作指南、设计契约或证据时才新增，并加入导航；普通进度放根 TODO/changelog，不重复造计划。
- 操作指南描述当前用户可执行行为；设计契约描述不变量和边界；日期记录描述当时证据。三者不能互相冒充。
- 写“已支持/已完成/通过”前核对实现与验证。计划尚未实现时明确写计划；记录旧测试数字或版本时保留日期，不能当作本轮结果。
- `AGENTS.md` 只存稳定规则。任务状态进 `../TODO.md`，已交付变化进 `../CHANGELOG.md`，人工步骤进 `../ACCEPTANCE_TESTS.md`，命令进开发流程；避免在各处复制完整规则和计数。
- 旧计划/验收记录保留历史原意；过时入口由导航注明“历史”，不要把旧发布包写成包含当前源码全部功能。
- 改文档后核对相对链接目标、示例路径、实际菜单文案和代码块；运行 `git diff --check`。纯文档改动无需机械运行构建或全量后端测试。
