# 本地数据集浏览

适合不同数据集分散在多个磁盘位置、每个数据集又有多层子目录，需要反复切换查看图片的场景。

## 开始浏览

1. 在首页“新建数据集”，每个独立数据集填写名称、选择本地根目录，然后扫描。扫描递归登记支持的文件，原文件保留在原位置。
2. 点击首页“本地浏览”，或数据集卡片上的“浏览”；详情页也有“浏览文件夹”入口。
3. 在左侧按名称或位置查找数据集，点击切换。各数据集保留本次浏览会话中的位置，返回时可继续查看。
4. 右侧文件夹卡片进入下一层；面包屑可回到任意祖先目录。“包含子文件夹”可平铺当前目录下已登记的图片。
5. 搜索文件名或路径，调整缩略图大小，点击图片进入大图预览；方向键切图、Esc 关闭。需要分拣或添加新文件时进入“数据准备”。
6. 按项目切换数据集；有类别或批次时，可用类别卡片和下拉筛选。类别/批次默认跨来源平铺，选择具体来源后再限定物理目录；勾选图片可批量设置归属。详细操作见 [项目、类别与批次](project-category-batch.md)。

## 浏览范围

- 浏览页只查询已登记的样本，不实时枚举整个磁盘。磁盘上新增文件后需重新扫描；没有已登记样本的空目录不显示。
- 默认查看图片，可切换全部文件类型。图片使用原比例预览；文件缺失或读取失败会提示，不会自动删除记录。
- 同一项目若曾扫描多个来源，选择“来源目录”后再浏览；不同来源中同名子目录分别展示。来源由登记路径推导，不作为完整的历史扫描清单。
- 来源内目录与展示位置由已登记绝对路径计算，旧库里相对路径不完整时仍尽量保留可定位的位置。换机器、移动目录或磁盘离线后，需通过原有文件修复/重新挂载流程恢复预览。
- 目录和文件均分页读取。搜索限定于当前目录，勾选包含子文件夹后覆盖其后代；文件夹计数包含后代，不随图片搜索条件变化。
- 浏览、搜索、切图及缩放不修改原图、分拣判断、标签、分组或项目版本；无需 GPU 或算法环境。
