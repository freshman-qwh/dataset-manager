# UI 文案词汇表

本词汇表用于统一 Dataset Manager 的按钮、筛选、状态、空状态和错误提示。新增界面文案应优先复用 `frontend/src/utils/uiCopy.ts` 中的常量；只有具体业务上下文需要完整句子时才扩展。

## 核心词汇

| 统一用语 | 避免用语 | 使用范围与说明 |
| --- | --- | --- |
| 数据质量 | 体检、数据健康、质量报告 | 详情页入口和概览名称。描述对文件、标注、划分和审核问题的检查能力。 |
| 数据质量工作台 | 体检弹窗、质量报告弹窗 | 数据质量的完整检查与问题定位界面。 |
| 审核状态 | 审查状态、标注状态 | 只表示未审核、待审核、已通过、已拒绝。不得表达标注是否完成。 |
| 标注进度 | 标注状态、未标注 | 只表示未开始、处理中、已完成 · 无目标、已完成 · 有对象。 |
| 样本标签 | 标签类别、标注类别 | 用于图片分类、数据整理和筛选的样本级标签。 |
| 对象类别 | 样本标签、标签 | 用于矩形或多边形对象的类别。与样本标签默认独立。 |
| 无标签 | 未标注 | 表示样本标签为空，不代表几何标注未完成。 |
| 已完成 · 无目标 | 空标注、未标注 | 用户已明确确认图片没有目标，是合法完成状态。 |
| 无目标图片 | 空标注图片、空样本 | 指已确认无目标，或在导出范围选项中包含无对象图片。 |
| 导出检查 | 导出预检、预检 | 导出前对范围、格式兼容性和阻断问题的检查。 |
| 不可用文件 | 异常文件 | 缺失或无读取权限的文件；具体原因应在详情中继续显示。 |
| 临界可接受 | 勉强 OK | 对应已有 `borderline` 等级；默认不作为纯正常训练候选，文案变化不改判定数据。 |
| 待定 | 待确认（用于分拣时） | 表示尚未作出 OK/NG 结论；与几何标注的待确认、审核状态分别管理。 |
| 文件可用 | 正常（用于文件状态时） | 表示文件能读取，避免与图像判定为正常混淆。 |

## 入口层级

- 首页说明“本地工业数据准备与快速验证”，新建突出准备目标、名称和可选图片目录；标注与补充资料按需展开。
- 数据集主操作随准备状态变化；“添加图片”“快速分拣”提供稳定次要入口，验证与训练包是两条交付路径。
- 分拣判定/工件筛选与普通文件/标签筛选分别收纳，活动条件显示“已启用”并自动展开；清除条件后恢复默认。
- 采集问题统一称“数据质量检查”。验证组件配置、输入尺寸和 ROI 按需展开，已有 ROI 在摘要中明确显示。
- 同一管理区域只保留一处分拣目录导出与旧目录映射；“导出元数据”明确区别于含图片的训练包。

## 状态约束

- “未开始”只属于标注进度；“未审核”只属于审核状态；“无标签”只属于样本标签。
- “已完成 · 无目标”与“已完成 · 有对象”都计入标注完成度。
- 对象类别不会在保存时自动写入样本标签；只有用户明确执行同步动作时才追加。
- 错误提示先说明用户影响，再说明可执行的下一步；内部 issue code 只作为次级诊断信息。

## 入口约束

- 数据集详情页首屏只突出一个随上下文变化的建议操作。
- 数据概览承载统计、分布和扫描结果；管理与导出承载质量、划分、标签、导入和导出。
- 相同功能在同一页面作用域内只保留一个可见入口，避免“数据质量 / 数据健康 / 体检”等并行名称。
