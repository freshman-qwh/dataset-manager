# Dataset Manager v0.4.1

发布日期：2026-09-08

## 版本定位

v0.4.1 完成本地优先数据准备工作台在“长任务可信执行 → 数据版本可复现 → 常用队列复用 → 精确重复泄漏解释”上的阶段闭环。所有能力继续以 SQLite 元数据和应用 storage 为边界，不自动修改原始数据文件。

## 主要能力

- SQLite 元数据备份：在线一致性复制、结构版本、核心表计数、外键、`quick_check`、SHA-256、取消/失败清理、重试和下载。
- 数据版本与快照：单调 dataset revision、不可变轻量快照、样本级差异分类、历史训练标签重建和确定性 hash。
- 保存视图与队列：保存筛选、排序、队列范围和创建时任务类型，支持恢复、删除与兼容的几何标注队列入口。
- 精确重复与泄漏：复用 SHA-256 解释跨 train/val/test 泄漏，支持全局摘要、有界分页、单组有界明细和完整 hash 定位。

## 数据库升级

本版 migration head 为 `20260907_0005`。升级现有数据库前必须停止后端和其他数据库使用者；使用项目数据库升级命令时，会先创建并校验备份，再在临时副本中迁移，全部检查通过后才替换目标数据库。

本版包含三项增量结构变化：

1. `20260904_0003`：数据集 revision。
2. `20260906_0004`：不可变轻量快照。
3. `20260907_0005`：数据集保存视图。

## 验收边界

- 后端全量测试、语法编译、前端生产构建和差异格式检查必须通过。
- 数据库、storage、日志、缩略图、任务产物和验收临时目录不得提交。
- 原始数据目录保持只读；备份、快照、重复检查和导出只生成应用管理的派生产物或 SQLite 元数据。

## 后续版本

下一阶段从 E2C 近重复与唯一性可行性门槛开始：先定义预计算/本地 embedding 输入、距离与阈值、可复现性、缓存和资源上限，再决定最小实现。离线 prediction 导入与样本级评估继续作为独立后续切片。
