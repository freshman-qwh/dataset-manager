# 前端工作规则

继承根 [AGENTS.md](../AGENTS.md)。本文件仅补充 `frontend/` 范围。

- 使用当前 React 18 + TypeScript + Vite + Tailwind v3；先沿用 `src/components` 和全局样式，再考虑新抽象。API 返回类型集中维护并与后端 schema 对照。
- 页面按用户任务组织：工业主线突出下一步；通用标注、管理和历史功能保留场景入口。不要把研发实现名或完整参数列表放进首次使用流程。
- 保持主要操作与次要操作的视觉层级；减少重复状态与并排竞争按钮。新增菜单需有清晰名称、可点击外部关闭、键盘/焦点路径和窄屏布局。
- 切换数据集、筛选、分页或样本时防止旧请求覆盖新状态；保存成功再推进队列。输入、中文输入法、快捷键和未保存离开保护需同时考虑。
- 画布与对象列表各自稳定约束，不因对象数量扩大页面；长名称应换行或截断并可读取，空数据/错误/加载/禁用状态需给出下一步。
- 界面或交互改动运行 `npm run build`，并尽可能用真实浏览器检查受影响页面、关键操作和窄屏。浏览器检查使用隔离示例，不修改实际项目判定来验证 UI。
- 无前端测试框架时，用构建和可复现的浏览器路径验证；不要为低影响文案或样式改动引入新测试依赖。始终检查 `git diff --check`。
