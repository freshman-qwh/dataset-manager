# 后端工作规则

继承根 [AGENTS.md](../AGENTS.md)。本文件仅补充 `backend/` 范围。

- 修改 API 前检查 `app/api/`、对应 schema/service 和已有测试；路由负责参数与 HTTP 错误映射，事务、预检和文件操作放 service。
- 持久化结构变更同时检查模型、Alembic revision、旧库维护状态、备份/恢复计数及相关导入导出契约。不要向冻结启动回填增加新表以绕过迁移。
- 长操作沿用现有本地 jobs。冻结输入、进度、取消、失败清理、重试和重启恢复按现有任务模式处理，不引入外部分布式队列。
- 修改分组、分拣、split 或验证逻辑时，检查版本冲突、事务回滚、历史真值、测试曝光与父模型引用，不用当前状态重写历史结果。
- 基础依赖保持轻量。SAM 与 Anomalib 属可选能力；测试应说明可选组件跳过原因，不能把跳过当算法验证成功。
- 文件/数据库测试使用隔离临时目录，禁止指向实际用户原图或唯一数据库。pytest 的临时目录与命令见 [开发流程](../docs/development-workflow.md)。
- 后端行为变更运行 `compileall app tests` 和相关 pytest；改到共享存储、迁移、任务、导出/恢复或通用样本逻辑时扩大回归。始终检查 `git diff --check`。
